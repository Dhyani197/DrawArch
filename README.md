# DrawArch

### Mobile DWG Viewer and Editor — UX/UI Design Project

DrawArch is a UX/UI design project for a mobile application that helps users
view, measure, annotate, edit, organize, and share technical DWG drawings
on Android and iOS devices.

The project focuses on simplifying complex CAD workflows for mobile users
while keeping the interface organized, accessible, and practical for
technical drawing tasks.

## 🎯 Problem

Traditional CAD workflows often depend on desktop workstations.
When users are working on-site, travelling, or away from their main
workstation, accessing and working with technical drawings can become
difficult.

DrawArch explores a mobile-first approach to make essential CAD
workflows easier to access on a mobile device.

---

## 💡 Project Objective

The objective of DrawArch is to design a simple and organized mobile
CAD experience that allows users to perform essential drawing-related
tasks without being overwhelmed by complex CAD interfaces.

The design focuses on:

- Simple navigation
- Clear tool organization
- Easy access to frequently used functions
- Mobile-friendly interactions
- Readable technical information
- Efficient drawing workflows

## 🧠 UX Research

The research focused on understanding how users interact with CAD
drawings and what they need when working away from a desktop environment.

Key research themes included:

- Mobile devices are useful for reviewing drawings in the field.
- Measurement and markup are important for on-site work.
- Users need quick access to frequently used tools.
- Complex CAD functionality needs clear organization on mobile.
- File management and sharing are important parts of the workflow.
- Users benefit from a simple and focused interface.

---
## 🗺️ Main User Journey

The primary DrawArch workflow is:

**Open My Files → Find DWG → Drawing Viewer → Measure / Markup / Edit → Save & Share**

The interface organizes complex CAD functionality into focused areas
to make the workflow easier to understand.

---

## 🧩 Main User Flows

### View & Measure

**My Files → DWG → Viewer → Measure → Select Points → Measurement Result**

### Markup & Edit

**Drawing → Markup/Edit Mode → Select Tool → Canvas → Save**

### Share

**Drawing/File Info → Share → Permission → Send/Link**
